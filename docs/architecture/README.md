# System Architecture — Web-Based Boarding House Finder

**Team:** Fourward Devs  
**Block:** BSIS 4-1  
**School:** Sorsogon State University (SorSU), Bulan Campus

## Project Overview

This folder contains the proposed architecture diagrams for the Web-Based Boarding House Finder for SorSU Bulan Campus students. The diagrams describe the system context, components, processes, data model, and proposed deployment architecture.

These diagrams are conceptual designs based on the planned MVP features and may be refined during system development.
